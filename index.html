TypeHebrew

TypeHebrew is an online Hebrew Beta Code to Unicode converter. When you type Beta Code into the dark box, the site turns it into Unicode Hebrew above it, along with a transliteration. Pick a transliteration scheme from the menu, and use the "SELECT ALL" and "COPY" buttons to grab either line. Click any entry in the key to insert its code where your cursor is. The coding follows CCAT's Beta Coding standard, with cantillation marks typed as their two-digit Michigan-Claremont numbers.

Transliteration has to guess in a few places that the pointing leaves open. A shewa after a long vowel is read as vocal. A qamets before a silent shewa is read as qamets hatuf (o), so add a meteg (|) to a qamets whose shewa is vocal: qf|+:lw. gives qāṭəlû.

The Hebrew typeface you see is SBL Hebrew, hosted locally with the help of Font Squirrel's brilliant webfont generator. The Beta Code is set in Raph Levien's Inconsolata and the interface in Huerta Tipográfica's Bitter, both served via Google Fonts. I'm also indebted to HTML5 Boilerplate, ZURB's jQuery TextChange Plugin, and Cloud9 IDE, which made building the first version of this site much easier.
